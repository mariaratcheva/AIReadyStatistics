The Federated Semantic Discovery Layer (FSDL): Focuses on semantic routing for AI systems via APIs (specifically protocols like MCP) across a distributed network of trusted data providers. FSDL does not host or index data for web browsers. Instead, when an AI assistant receives a question like "What is the population of England?", it queries the FSDL first. The FSDL looks at the metadata and responds to the AI: "The statistical authority for this concept/geography is the UK Office for National Statistics (ONS). Here is their live MCP endpoint and parameter structure to call." The AI then connects directly to ONS to fetch the real-time, official number along with footnotes, caveats, and methodology. FSDL only stores meta-knowledge: which organization owns what statistical domain, and how an AI can contact them. Google Search interacts with the web primarily via standard HTTP web scraping, HTML rendering, and Schema.org metadata embedded on web pages. FSDL relies on MCP (Model Context Protocol)—a protocol designed for AI models to discover, read, and invoke tools, context, and data sources dynamically.
