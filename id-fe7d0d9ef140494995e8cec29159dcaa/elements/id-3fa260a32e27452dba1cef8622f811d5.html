Native Query / Dialect Payload Translates the semantic layer's Intermediate Representation (IR) into native instructions for the target engine: For Data Warehouses (SQL): Generates target-specific SQL (e.g., Snowflake dialect vs. BigQuery dialect) including joins, aggregations, and row/column security predicates. For Vector Databases: Provides the query vector embedding, distance metric (e.g., cosine similarity), top-k count, and metadata filter payload. For Statistical Endpoints (SDMX/REST): Formats the URI path, header parameters, and REST dimensions according to statistical data structure definitions (DSDs). 3. Security & Governance Rules (Injected Predicates) Carries non-bypassable security directives enforced during query execution: Row-Level Filtering: Mandatory WHERE clauses injected based on user entitlements (e.g., WHERE region = 'CA'). Column Masking / Redaction: Instructions to hashing/redacting sensitive fields at the storage level. Data Lineage Headers: Attaches audit metadata to trace the origin of every retrieved record. 4. Post-Processing & Response Contract Specifies how the raw payload returned by the target engine must be transformed before reaching the client: Format Standardization: Converts raw database result sets into canonical JSON, SDMX-JSON, or JSON-LD. Zero-Hallucination Guardrails: Forces strict binding between raw numerical values and their authoritative metadata/methodology notes. Semantic Annotation: Appends URI references from the semantic layer's ontology so downstream AI agents or BI tools can interpret field definitions correctly. Execution Lifecycle of a Routing Instruction Generation: The Routing Engine constructs the instruction set after evaluating the user's intent, domain rules, and security context. Dispatch: The instruction is dispatched to an Execution Connector / Adapter specific to the target system. Execution: The adapter executes the native spec against the target system (e.g., issuing an SDMX REST call or executing a SQL query). Validation: The returned payload is validated against the Response Contract specified in the instruction to guarantee correctness and compliance before serving the response.
